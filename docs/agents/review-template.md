# Чеклист ревью

```text
Контракт MCP: не изменились ли имена tools, аргументы и форма ответа?
Клиенты: применимы ли инструкции к Claude Code, Claude.ai, Codex и ChatGPT?
OAuth: public URL HTTPS, redirect origins точные, токены и секреты не попали в diff?
Данные: timezone, пагинация, кэш и single-use refresh token сохранены?
Медицина: нет ли диагноза, лечения или опасного совета?
Тесты: покрывают ли новый наблюдаемый сценарий и проходят ли офлайн?
Документация: обновлены ли обе README и нужный deployment/runbook?
Релиз: синхронны ли версия, `server.json`, lockfile и changelog при их изменении?
```

Замечания должны указывать файл, риск и ожидаемый результат. Одобрение без
запуска проверок должно явно сказать, какие проверки не выполнялись и почему.

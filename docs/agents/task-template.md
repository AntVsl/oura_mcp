# Бриф задачи

Скопируй этот шаблон в описание задачи или pull request перед работой, если
изменение затрагивает больше одного файла.

```text
Цель:
Не-цели:
Владелец задачи:
Файлы в моей зоне:
Изменения других агентов, которые нужно сохранить:
Клиенты / контракты, которых это касается:
Риски для OAuth, токенов или медицинской границы:
Критерии приёмки:
План проверок:
```

После выполнения допиши: изменённые файлы, команды проверки с результатом и
оставшиеся ограничения. Никогда не вставляй в бриф секреты или фрагменты
реальных данных Oura.
